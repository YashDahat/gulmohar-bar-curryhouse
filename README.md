# Gulmohar Bar & Curryhouse

Auto-generated website for Gulmohar Bar & Curryhouse — North Indian restaurant, Kapil Malhar, Baner, Pune, Maharashtra 411069.

## Tech Stack

- **backend**: Spring Boot 3.x + Spring Data JPA + Spring Security
- **hosting**: AWS App Runner (backend) + Vercel (frontend)
- **payment**: Razorpay
- **database**: PostgreSQL
- **frontend**: React 19 + Tailwind CSS + Shadcn/UI

## Features

- Mobile-First Responsive Design
- Online Table Reservation System
- Online Ordering for Delivery & Takeaway
- Razorpay Payment Gateway Integration
- Interactive Digital Menu with High-Quality Images
- Google Business Profile Integration (Reviews, Hours, Map)
- Click-to-Call and Click-to-Navigate functionality

## Running Locally

```bash
docker-compose up --build
```

The app will be available at http://localhost:8080

## Development

**Backend:**
```bash
cd backend && mvn spring-boot:run
```

**Frontend:**
```bash
cd frontend && npm install && npm run dev
```
